  E3 · NAIVE BAYES — ¿qué supuesto se ajusta a los datos?
══════════════════════════════════════════════════════════════════════════════════════

── Justificación ───────────────────────────────────────────────────────────────────
   Naive Bayes supone que las variables son independientes entre sí
   dado el objetivo. Además, cada variante asume una distribución:
     · Gaussiano  → variables continuas con distribución normal
     · Categórico → variables categóricas con probabilidades por nivel
   Las numéricas continuas se DISCRETIZAN en 5 intervalos por cuantiles
   para que el categórico pueda procesarlas.

   NOTA: Naive Bayes no tiene versión de regresión. Para la dimensión
   del equipamiento se aplica sobre nivel_equip, la categorización de ieh.
   [bitácora E-05] Discretización para Naive Bayes categórico

                            multiclase F1 macro 0.4821
   Naive Bayes categórico   AUC 0.8017 · F1 0.8297 · recall mín. 0.6835 · 0.5s
                            multiclase F1 macro 0.6107

   Diferencia de AUC (categórico − gaussiano): +0.0276
   CONFIRMADO: el supuesto adecuado a la naturaleza de los datos
   produce mejor modelo. Elegir la variante según el tipo de variable
   no es un detalle técnico sino una decisión que afecta al resultado.

   ¿POR QUÉ EL DIBUJO DEL ÁRBOL MUESTRA gini = 0,5 EN LA RAÍZ?

   Es la variable que más reduce la impureza de todas las disponibles.
